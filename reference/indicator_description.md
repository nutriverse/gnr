# Description of variables that occurs in the Global Nutrition Report (GNR) dataset

Description of variables that occurs in the Global Nutrition Report
(GNR) dataset

## Usage

``` r
indicator_description
```

## Format

A data.frame with 709 rows and 3 columns:

- `section`:

  Section of the report

- `variable`:

  Data variable

- `description`:

  Description of variable

## Source

[Global Nutrition Report](https://globalnutritionreport.org)
